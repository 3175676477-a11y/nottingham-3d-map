# 月面观测与旋转中心

从太空页选择“站在月球上看天空”。月面页支持纬经度、近地面/月背预设、拖动环顾、滚轮缩放、UTC 日期时间、播放速度，以及看地球/太阳/地平线按钮。

地球使用与太空页相同的 Natural Earth 50m 大陆轮廓纹理（2048×1024）；配色为示意，不是卫星照片。默认天体显示为真实角大小的四倍，可切换 1× 或 8×。高度和方位读数始终对应中心的计算位置，不随显示倍率变化。地球自转和光照方向在月面局部坐标中变换，不把地球纹理固定朝向相机。

月面参考系采用 IAU 平均极轴 RA=269.9949°、Dec=66.5392°，本初子午线 W=38.3213°+13.17635815°d（d 从 J2000 起算）。这是简化平均旋转模型，未加入 IAU 周期修正项、精密天平动、食或真实地形遮挡。天体方向沿用项目的近似轨道模型，并计入月球半径造成的观测位置偏移。地球在近地面几乎固定，仅小幅摆动；月背不可见。太阳升落周期约 29.53 地球日，日照区间数值搜索水平地平线中心高度过零，不使用地球的 24 小时日照公式。

轨迹显示固定的约一个朔望月区间，标明起止 UTC 日期；仅画地平线以上的段。太阳与地球下半球由水平裁剪面遮挡。星空、平坦月面和暗面辅助光为展示用途。

太空页的太阳、地球、月球名称现在都是按钮：点击切换 OrbitControls 中心，播放期间持续跟随所选天体。左上方还有三个固定按钮，方便目标在屏幕外时切换。地球表面点击仍进入该地点的地面天空，月面入口独立。
